## Production rules

- Use Framer Motion for spring and scroll choreography, native canvas for the solar field and CSS scroll timelines as progressive enhancement.
- Do not add a general-purpose 3D runtime unless the brand gains an identity-specific object that justifies it.
- Cap canvas pixel density, pause work in background tabs and preserve a complete static composition under reduced motion.
- A motion detail stays only when it strengthens hierarchy, orientation or the central idea that Sun Street makes change move.
